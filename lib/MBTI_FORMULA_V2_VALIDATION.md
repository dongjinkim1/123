# MBTI 인지기능 강도 공식 v2 — 적대적 재검증 로그

- **대상**: `lib/mbti-profile.v2.js` (신규) vs `lib/mbti-profile.experimental.js` (baseline, 회귀 기준 — 보존)
- **방법**: 정답 데이터 부재 → "N/M 합격"이 아니라 **① 이론 정합성 자동 게이트 + ② 보정의 이론 비판 + ③ baseline 대비 개선 입증**
- **핵심 차이**: baseline은 검증 완료됐으나 한계 2개 잔존 — 이번 v2는 그 2개를 보정하고, 새 모순을 만들지 않았는지 적대적으로 재검증한다.
- **원칙(정직성 게이트)**: "이게 정답"이라 단정하지 않는다. 보정이 순서를 깨면 억지 통과시키지 않고 방식을 고친다. v2가 baseline보다 명백히 낫지 않으면 "baseline 유지"를 판정할 수 있다.
- **적용 범위**: 검증 전용. 프로덕션 원본 적용은 **동진 승인 후 별도**.

## §0. v2가 푸는 baseline 한계 2개

| # | baseline 한계 | 근거 | v2 보정 |
|---|--------------|------|---------|
| ① | **E/I·J/P 축이 무반영(inert)** — S/N·T/F만 발현강도에 들어감 | 실증: E/I·J/P만 바꾸면 발현강도 동일 (16/16 flat) | 보정1(E/I→주), 보정2(J/P→외향기능) |
| ④ | **열등 역설** — 종류축이 강할수록 열등기능이 오히려 **커짐** | 실증: 16/16 타입에서 공유축 55→88일 때 열등 0.231→0.255 증가 | 보정3(열등 방향 억압) |

baseline은 주기능 태도(E/I)와 외향기능 지표(J/P)를 "스택 결정에 소진"하고 발현강도엔 쓰지 않았다. 검사자가 입력한 E/I·J/P 강도가 결과에 전혀 안 보이는 것은 서비스 체감상 약점이다. ④는 더 분명한 모순: 선호가 뚜렷할수록(종류축 강) 그 반대인 열등기능은 **더 억압**돼야 하는데 baseline은 거꾸로 키웠다.

## §1. v2 공식 정의

baseline 파이프라인(compressed 종류강도 × 위치가중 × balance)을 **그대로 유지**하고, 그 위에 곱셈 보정층 3개를 얹는다. balance는 보정 전 base에서 계산해 baseline의 폭주 신호를 보존한다.

```
norm(L) = (L - 55) / 33          // 55→0, 68→0.394, 88→1.0
α = 0.2, β = 0.3, capEps = 0.02  // 수렴값(§7)

[보정1 — E/I → 주기능]  주기능 태도 = E/I 방향 (MBTI 정의)
  I유형(주=내향): corrEI = 1 + α·norm(EI_level)
  E유형(주=외향): corrEI = 1 + α·norm((EI_level + JP_level)/2)   // E/I·J/P 평균 결합 → 이중가산 방지

[보정2 — J/P → 외향기능]  J/P는 항상 외향기능을 가리킴
  I유형(부=외향): corrJP = 1 + α·norm(JP_level)
  E유형: J/P는 보정1의 주기능에 이미 결합 → 부기능(내향) 보정 없음

[보정3 — ④ 열등 방향]  열등 = 선호 반대극, 분화 강할수록 억압
  corrInf = 1 - β·norm(열등종류축_level)     // 열등종류축 = 주기능과 공유

발현[주]   = baseline[주]   × corrEI
발현[부]   = baseline[부]   × corrJP
발현[3차]  = baseline[3차]               // 보정 없음
발현[열등] = baseline[열등] × corrInf

[순서보존 cap]  타입역학 공리: 부는 주를 보조하되 넘지 못함
  발현[부] = min(발현[부], 발현[주] × (1 - capEps))
```

**왜 cap이 필요한가**: 보정2가 부기능을 키울 때, 부축이 주축보다 강하면(예: 부축 N88, 주축 F55) compressed로 좁혀 둔 폭을 J/P 보정이 다시 벌려 **부>주 역전**이 난다. cap은 이 한 지점만 클램프한다. 3차는 무보정, 열등은 축소만 하므로 그 외 순서는 자연 보존된다. 따라서 **순서를 깰 수 있는 경로는 보정2뿐이고, cap이 그것만 막는다.**

## §3. 적대적 5역할 — ROUND 1

### 3-1. 레드팀 (v2 공격)

**공격 A — "cap은 반창고다. 1296 중 40건(3.1%)에서 J/P 신호를 잘라 순서를 가짜로 맞춘다."**
→ 반박(검증관): cap이 발동하는 건 **부축이 주축보다 강하고 J/P까지 강한** 구석뿐이다. 그 구석에서 타입역학은 "주기능이 1차"임을 **무조건** 단언한다(검사 %가 뒤집을 수 없음). 클램프는 정보 손실이 아니라 **검사 %가 구조 공리를 못 넘는다는 사실의 강제**다. 게다가 클램프돼도 부는 무보정값(0.74)보다 위(0.781)로 올라가므로 J/P 체감은 살아 있고, 공리를 위반할 부분만 제거된다.

**공격 B — "보정3은 열등축=주축이라, 결국 '주기능이 강하면 열등 억압'일 뿐. 열등 고유 정보가 아니다."**
→ 반박: 열등은 정의상 주기능과 같은 축의 반대 태도(Ni↔Se). 한 사람이 그 축에서 주 쪽으로 강하게 기울수록 반대극(열등)은 더 억압된다 — 이게 바로 융의 "열등 = 가장 분화된 기능의 반대 = 가장 억압". 공유축 강도를 쓰는 게 정확히 맞다.

**공격 C — "E유형은 J/P를 주기능에 넣어버려서, E유형의 내향 부기능은 아무 보정도 못 받는다. 비대칭 아닌가?"**
→ **인정(정직)**: 사실이다. E/I와 J/P **두 태도축이 모두 외향기능을 가리킨다**(E/I는 외향인 주를, J/P는 외향기능을). 그래서 E유형 내향 부기능(ENFP Fi, ENTJ Ni)엔 척도 신호가 없어 baseline 그대로다. 이는 4글자→8기능 매핑의 **구조적 한계**이지 버그가 아니다. §8에 잔여로 공개한다.

**공격 D — "④ 해결을 others=68에서만 봤다. 다른 축이 극단이면 역설이 되살아나지 않나?"**
→ 반박: 열등 발현 = compressed(L)×0.3×balance(L)×(1-β·norm(L)). 공유축 L이 오를 때 compressed(L)는 오르지만 balance(L)와 corrInf(L)는 둘 다 내려간다(주축=L이 커져 balance 비율↓). 곱은 단조감소 — 다른 축 값과 무관. 전수 1296에서 열등 위치 순서 위반 0으로 재확인.

### 3-3. 검증관 (수학자 + MBTI전문가, 상호 견제)

- **수학자**: 순서 보존은 cap이 **임의의 α에서 보장**한다 — 스윕 전 행에서 위반 0(§7). 증명 골자: ①보정1은 주만 키워 순서에 유리, ②보정3은 열등만 줄여 3차>열등 강화, ③3차 무보정, ④유일한 역전 경로(보정2의 부)를 cap이 주×0.98로 클램프, ⑤부>3차는 base 비율 1.6과 cap이 함께 보장. 따라서 α는 순서 제약이 아니라 **체감/왜곡 트레이드오프** 파라미터.
- **MBTI전문가**: 세 보정이 각각 교과(주태도=E/I, J/P=외향기능, 열등=억압된 반대극)에 대응. 단 E유형 내향 부 무정제는 입력 한계로 인정.

- **v2 vs baseline**: v2는 baseline의 한계 2개(① 무반영, ④ 역설)를 **측정 가능한 수치로** 제거하면서(E/I·J/P 16/16·16/16 반응, ④ 16/16→0/16), 순서 위반 0과 새 모순 0을 유지했다. 스펙이 명시한 서비스 기준(순서 0 + 4축 체감 + ④ 해결 + baseline 대비 개선)에서 **v2가 baseline을 지배**한다.

- **순서**: 모든 α에서 0 (cap 덕분). 즉 순서는 α 선택 제약이 **아니다**.
- **β**: ④ 해소 임계는 β≈0.07(열등 상승비 1.16을 (1-β) 가 눌러야 함). β=0.3은 충분한 여유 — 최강축에서 열등 ×0.7로 분명히 억압하되 음수/소실 없음(하한 0.7>0). β=0.3 채택.
- **α**: 체감(Δ)은 α에 선형. α=0.2에서 Δ≈0.12(3버킷 스프레드의 의미 있는 폭)에 cap 3.1%로 왜곡 최소. α=0.25↑는 cap이 5.5~6.2%로 급증(구석 왜곡↑)하는데 체감 이득은 한계적. **α=0.2가 트레이드오프의 무릎**. 초안값이 곧 수렴값.

## §8. 정직하게 남기는 잔여 한계 (숨기지 않음)

- **A. 발현강도 상한 초과**: corrEI 최대 ×1.2가 baseline 천장(~0.88)에 곱해져 주기능이 **최대 ~1.05까지 1.0을 넘는다**(INTJ all-88 Ni 1.051, INFP I88F88 Fi 1.02). 6항목은 전부 상대 비교라 영향 없으나, 하위 코드가 발현강도 [0,1]을 가정한다면 **후처리 정규화(클램프 또는 전체 스케일)** 가 필요 — 동진 확인 사항.
- **B. E유형 내향 부기능 무정제**: E/I·J/P 두 태도축이 모두 외향기능을 가리켜, E유형의 내향 부기능(ENFP Fi, ENTJ Ni)은 척도 신호가 없어 baseline 그대로다. I유형 부(외향)는 J/P로 정제되는 것과의 **비대칭**. 4글자→8기능 매핑의 구조적 한계이며 현재 입력으로는 보정 불가.
- **C. cap은 자연 성질이 아닌 강제**: 보정2는 본래 순서를 보존하지 않는다. 3.1% 구석을 공리로 클램프하므로, 그 구석에서 J/P 체감은 부분적으로 평탄화된다(부가 주 직하에서 멈춤).
- **D. α/β는 서비스 튜닝값**: 심리측정으로 도출한 상수가 아니라 정합성/체감 트레이드오프에서 고른 값. "측정"이 아니라 "근사"임을 재확인.

## §9. 동진 승인용 3줄 요약

1. **v2는** baseline 위에 E/I→주·J/P→외향기능·열등 방향억압 보정 3개와 순서보존 cap을 얹은 공식이다(α=0.2, β=0.3, 회귀 안전장치로 baseline 완전 포함).
2. **baseline 대비** E/I·J/P 무반영(0/16→16/16)과 열등 역설(16/16→0/16)을 제거하면서 순서 위반 0·새 모순 0을 유지 — 서비스 기준에서 개선.
3. **이렇게 쓰면 됨**: 검증 전용으로 두고, 적용 전 두 가지만 결정 — (A) 발현강도가 ~1.05까지 가니 [0,1] 정규화 필요 여부, (B) E유형 내향 부기능 무정제를 수용할지. 둘 다 OK면 `mbti-profile.experimental.js` 자리에 v2를 승격.
