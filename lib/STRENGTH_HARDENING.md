### 발견 오류 (명리 검증관)

- **Flaw A — 운성·통근 중복 가산**: `unsW`(line 89)는 한 지지의 모든 지장간에 곱해진다. 단일 십성이 일지/시지의 **제왕·건록(1.5)** 에 앉으면 **통근(1.3)** 과 합쳐 1.5×1.3 ≈ **1.95배 이중 가산**. 12운성(왕쇠 phase)과 통근(뿌리 유무)은 **둘 다 "뿌리 강도"를 측정** → 중복. 그 결과 3~4배 더 분포한 격 십성이 약운성(사·묘·절 0.6) 자리에 있으면 단일 비겁에 역전.
- **Flaw B — 그룹 희석**: 변별(distinctiveness)은 십성 **개별** 채점. 편인+정인이 분산되어 그룹으로는 압도적인 인성이, 집중된 단일 비견에 밀림. → 단, A를 고치면 B도 함께 해소(둘 다 제왕·건록 부스트가 방아쇠).

### 개선 (가중치 단일 레버 — 명리 근거)

`STRENGTH_WEIGHTS.uns` **범위 압축** (다른 가중치·로직 무변경):

```
            제왕   건록   관대   장생   목욕   양    태     쇠    병     사    묘    절
원본:       1.5   1.5   1.3   1.2   1.0  1.0  0.9   0.8  0.7   0.6  0.6  0.6   (폭 0.90)
실험본:     1.25  1.25  1.15  1.10  1.0  1.0  0.95  0.9  0.85  0.8  0.8  0.8   (폭 0.45)
```

**명리 근거**: 운성을 보조 수식어로 축소(진폭 절반), 뿌리 신호는 통근이 주로 담당. **단조 순서(왕>관대>장생>목욕>쇠병사절) 보존** — 왕쇠 방향성은 유지하되 단일 지지가 다수 분포를 뒤집지 못하게 함.

### 심판 판정

- 케이스별 땜질 ✗ → **단일 원리(운성·통근 중복) 수정** ✓. 회귀 0 파손 → **통과**.
- **종격 3건(종살·종아) 잔존 → 보류로 재분류**:
  - 종격은 변격(특수격): ① 성립 여부(진종/가종)가 명리 최대 논쟁, ② 정의상 극신약/극신강이라 **신강도 척도 자체가 붕괴**, ③ "강한 특징" 정답이 학파 분열 — 종아격 [임신 신해 무술 신유]에서 편재(월령 해수 **득령**) vs 식상(**종신**)은 *월령우선 학파 vs 종신우선 학파* 갈림. **정답이 모호 → 보류가 명리적으로 정당**(반례 회피 아님).
