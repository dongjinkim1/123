## ROUND 1 — 중복 가산 (§4(1) 레드팀 공격)

### 공격 (레드팀)

> "충·형·원진·해는 **동일 지지쌍**에서 겹친다. 인신=충+형, 인사=형+해, 자미=해+원진. 그대로 더하면 한 쌍이 2~3번 카운트되어 마찰이 과대평가된다."

| 지지쌍 | 동시성립 | 순진한 합산 | 문제 |
|--------|---------|------------|------|
| 인신(2-8) | 충 + 무은지형 | 1.0+0.85 | 한 쌍 1.85배 |
| 인사(2-5) | 무은지형 + 인사해 | 0.85+0.4 | 한 쌍 1.25배 |
| 자미(0-7) | 자미해 + 원진 | 0.4+0.55 | 한 쌍 0.95배 |

### 명리 검증관 — 원리 확정

- 충·형·원진·해는 **단일 "마찰" 축의 강도 단계**다(충>형>원진>해). 한 쌍이 여러 마찰명에 해당해도 **작용은 하나** → 최강 1개만 인정.
- 합·암합은 **결합 계열**(별개 축). 마찰과 동일 쌍에서 공존 가능(예 사신=합+지세지형). → 결합은 마찰과 **독립 가산**.

### 수학자 — 단일레버 수정

`FRICTION_RANK = {충:4, 형:3, 원진:2, 해:1}`. 위치쌍 `i_j` 별 **점유 rank 최댓값만 유지**(`claim` 맵). 충을 먼저 시드 → 형/원진/해는 자기 rank가 기점유 rank보다 클 때만 기록. 결합(합/암합)은 claim 무관 독립.

### 재검증 (실증)

- INV3a 인신 충+형 → **충만** PASS · INV3b 인사 형+해 → **형만** PASS · INV3c 자미 해+원진 → **원진만** PASS.
- INV4a 사신 합+형 → **둘 다** PASS(결합·마찰 독립). INV4b 동거리 충(1.0)≥형(0.85)≥원진(0.55)≥해(0.4) PASS.

### 심판 — 통과

케이스 땜질 ✗ → **rank 기반 단일원리** dedup ✓. 명리(마찰 단일축)·수학(max-rank) 정합.

## ROUND 2 — 회귀 안전장치 (레드팀: "추가가 검증된 baseline을 오염시키는가")

### 공격

> "십성·신살 랭킹은 이미 9,408케이스로 수렴했다. 관계·레이어를 더하면서 그 결과가 1비트라도 바뀌면 검증 무효다."

### 수학자 — 위임 + 영점 보증

- **960/960** : `extras-off === fs` PASS.
- **960/960** : `extras-on + EXTRA=0` 의 topFeatures `=== baseline` PASS (타이 포함 byte-일치).

### 심판 — 통과

추가요소는 **순수 가산적**. 영점에서 baseline 복원 전수 입증 → 검증 무효화 우려 해소.

## ROUND 3 — 분류 게이트 (§4(2): "정말 (a)인가, (c)인가, (b)인가")

### 공격 (레드팀)

> "신강약·격국도 점수가 나온다. 왜 랭킹(a)에 안 넣나? 자의적 분류 아닌가?"

### 이론검증관 — 공통축 판별

핵심 테스트: **feature-strength 의 공통축(변별력/두드러짐 = 개별특징의 상대적 돌출도)에 올라타는가?**

- **신강약**: 사주 전체의 **스칼라 상태**(자강/타강 비율). 개별 특징의 돌출도가 아님 → 같은 척도로 "랭킹"하면 범주오류. **(c)**.
- **격국**: 구조 **성립도**(정격/특수격/파격)의 거친 라벨. 돌출도 축과 측정대상이 다름 → **(c)**.
- **오행결핍**: **부재(negative space)** 측정 — 돌출도와 **반대 극성**. 결핍은 "없음의 강도"라 두드러짐 랭킹에 직접 못 섞음 → **(c)**. 단, `el===0` 은 **정답 명확**(clarity gate clean) → 점수화는 가능(별도 레이어).
- **용신·조후**: 처방(문자열). 결정적 magnitude 없음 → **(b) 보류**.
- **납음·일주물상**: 상징(문자열) → **(b) 보류**.
- **관계(합충/형/해/원진/암합)**: 각 쌍의 **상대 돌출도**가 곧 의미 → 공통축에 올라탐 → **(a)**.

## 정직성 게이트 (잔존 한계 — 은폐 금지)

1. **베이스 한계 승계**: `saju-score.js`는 **프로덕션 원본** `feature-strength.js`를 래핑한다. STRENGTH_HARDENING 의 `uns` 압축 실험본은 **미적용**(동진 승인 대기) → 1980.8.18 정인격이 겁재 #1로 나오는 **baseline 반례는 그대로 잔존**. 이는 본 하네스가 도입한 회귀가 아니라 **앵커의 알려진 한계**.
2. **EXTRA 4값은 명리 서수**(충1.0>형0.85>원진0.55>해0.4)로 근거하나 **기수(절대크기)는 추정**. 관계는 max정규화로 진입하므로 랭킹은 서수에만 의존 → 영향 제한적이나 절대값 보정은 향후 과제.
3. **(c) 레이어 점수**(신강약/격국/결핍)는 랭킹 비교 **불가**(측정축 상이). magnitude 모듈레이터로만 cross-fusion 단계에서 소비할 것. 랭킹에 섞으면 범주오류.
4. **암합 cap=3**: 다발 시 포화. 명리적 무한가산 방지용 휴리스틱(절대근거 약).
