# 관찰자 보고 CP1

## 패턴 라인 관찰 보고 — 최근 30건 판정 메타

### 1. 편향 경보

**축 쏠림 — 비겁 단일 축 포화 (고신뢰)**
- 30건 전부가 겁재/비견을 주연으로 함. 편재·편관·편인·식신이 주연인 건은 0 (식신·상관은 출구/경유 조연으로만 등장).
- 강약 전제도 신약 압도적(10건+). 신강은 YAD-004의 falsify 조건으로 단 1회 언급. 중화는 2건(007, 017)뿐.

**판정 사유 단일화 (고신뢰)**
- reject 5건 전부 동일 사유: "산출 가드 tags 2~4 위반" — 즉 내용·논리 기반 reject가 0건. 가드를 통과한 건의 accept율 100%. 판정기가 형식 게이트 이후로는 변별을 못 하고 있거나, 생산 라인이 이미 판정 기준에 과적합됐을 가능성 양쪽 모두 열려 있음.

**형식 쏠림**
- 파생 형식이 태그 가드에 구조적으로 취약: 첫 시도 4/4 전멸 후 재시도 전원 통과. 파생 생성 경로만 태그 규격을 못 맞추는 계통적 결함 신호.
- MBTI 측은 열등기능 병리 서사 편중 — Se_inf "전부-아니면-전무"(006, S509, S511), Fe_inf 개시비용(015) 등. H2-YAD-006 골격이 파생 3건에 재사용되어 다양성 대비 골격 농도가 높음.

### 3. 융합 가설

**가설 A — 운성 게이트 × 열등기능 분출 시간차.** 011의 "쇠 운성이 입력을 어중간한 수용으로 감쇠"와 006 계열의 "Se_inf 전부-아니면-전무 분출"을 직렬 연결하면, 감쇠된 수용이 누적되다 운성 전환점(쇠→병 또는 묘→절)에서 일괄 방류되는 '운성 12단계를 분출 타이밍 게이트로 쓰는' 교차 구조가 가능. 두 라인 모두 이미 accept된 기제라 결합 비용이 낮음.

**가설 B — 신살 캐스팅보트의 출력 방향 분기.** 014(천덕=동류 조력 경로 특정)와 019(화개=단독 작업 고립 벡터)는 동일한 비견 입력에 대해 정반대 출력 방향을 신살이 결정하는 구조를 각각 절반씩 갖고 있음. 쌍둥이대조 형식과 결합하면 '신살만 다른 동일 원국' 대조가 자연스럽게 성립.
