# MBTS 무료 80타입 — 소주제별 특징 2개

> 오행×MBTI 80타입. 소주제(핵심기질·강점·약점·연애·사회)마다 특징 2개.
> 파이프라인: 생성 → 테스터(공감) → 검증(공감+스타일규칙 ⓐ바넘 ⓑ오행결 ⓒ담백) → 코드+의미 교차검증 → 오행 변별 교정.
> 오행 융합각도(프로즈용)는 features80.json 참조.

## 물

### 물INTP
- **핵심기질**: 답이 맑아질 때까지 생각을 속으로 가라앉혀 곱씹는다 / 겉은 잔잔해도 한 주제를 깊은 바닥까지 가라앉으며 따라간다
- **강점**: 성급한 판단을 가라앉혀 충분히 맑아진 답만 길어 올린다 / 표면 아래 깔린 가장 깊은 전제까지 내려가 짚어낸다
- **약점**: 머릿속 결론이 출구를 못 찾아 안에 고인 채 빠지지 않는다 / 속이 깊어 불투명한 탓에 가까운 사람도 안을 못 읽는다
- **연애**: 끌려도 먼저 솟구치지 않고 상대가 흘러오기를 가만히 기다린다 / 한번 마음이 스민 사람은 오래 젖은 채 잘 마르지 않는다
- **사회**: 무리에선 눈에 안 띄는 가장 낮은 자리로 흘러가 가라앉는다 / 있는 듯 없는 듯 머물러 빠진 뒤에야 빈자리가 뒤늦게 드러난다

### 물INTJ
- **핵심기질**: 결론을 서두르지 않고 생각이 충분히 가라앉을 때까지 묵혀둔다 / 눈앞의 상황보다 그 아래 깔린 구조와 원인을 먼저 본다
- **강점**: 한 주제를 바닥까지 파고들어 남들이 못 닿는 깊이에 도달한다 / 감정이 출렁여도 판단만은 가라앉혀 냉정을 유지한다
- **약점**: 다 따져 확신이 설 때까지 미루다 움직일 때를 놓친다 / 혼자 다 짊어지고 삭이다 속에서 곪을 때까지 안 꺼낸다
- **연애**: 단번에 빠지지 않고 천천히 스며들듯 마음을 들인다 / 한번 깊어진 마음은 웬만해선 흔들리거나 식지 않는다
- **사회**: 무리에 섞이기보다 한발 물러나 전체 흐름을 관찰한다 / 넓게 사귀기보다 신뢰가 고인 소수와만 깊이 어울린다

### 물ENTP
- **핵심기질**: 반대 의견이 들어와야 그 생각이 진짜인지 가늠이 돼요 / 겉으론 흘려듣는 듯해도 속으론 그 말의 약한 데를 다 짚어놔요
- **강점**: 눈앞의 증상 말고 그 아래 가라앉은 진짜 원인을 짚어내요 / 흩어진 정보를 한참 묵혀 두면 저절로 한 줄기로 모여요
- **약점**: 판을 새로 까는 건 신나는데 마무리 20%에서 손을 놔요 / 논리로는 이겼는데 그 말에 사람이 베인 걸 늘게 알아요
- **연애**: 위로받고 싶다는 말에 원인부터 캐묻다 분위기를 식혀요 / 진지한 감정 얘기 앞에선 농담으로 슬쩍 빠져나가요
- **사회**: 무리 속 겉도는 말 밑으로 가라앉아 안 꺼낸 분위기를 읽어요 / 따로 노는 사람들을 한 줄기로 합쳐 흐름을 만들어요

### 물ENTJ
- **핵심기질**: 겉으로 드러난 흐름 아래에서 판이 진짜 어디로 향하는지를 먼저 읽어요 / 말의 표면보다 그 밑에 깔린 진짜 의도를 먼저 가라앉혀 봐요
- **강점**: 흩어져 제멋대로 번지던 변수를 한 줄기로 끌어모아 수렴시켜요 / 압박이 셀수록 오히려 수위를 낮추고 차분히 결단을 흡수해 내요
- **약점**: 판단은 다 끝났는데 과정을 안 드러내 사람들 사이에 벽을 세워요 / 혼자만의 흐름으로 너무 깊이 가라앉아 곁에서 닿기 어려워해요
- **연애**: 챙기는 건 다 하면서 정작 제 힘든 바닥은 끝내 안 비춰요 / 좋아할수록 관계 전체의 흐름을 정해두고 관리하려 들어요
- **사회**: 무리에 들어가면 누가 진짜 결정권자인지부터 가려내요 / 시키지 않아도 판을 정리하는 자리로 자연스레 흘러가요

### 물INFP
- **핵심기질**: 좋아하는 건 마음 밑바닥으로 천천히 가라앉혀 거기 오래 고여 두는 편이에요 / 바깥 신호는 다 받아 담으면서 정작 자기 기분엔 끝내 이름을 못 붙인다
- **강점**: 진짜 하려던 말과 그냥 한 말의 온도 차를 티 없이 조용히 읽어낸다 / 한번 마음에 고인 애정은 유행이 다 빠진 뒤에도 혼자 오래 데운다
- **약점**: 고인 감정이 어느 선을 넘으면 예고 없이 마음 문을 차갑게 닫아버린다 / 싫은 소리를 삼키다 정작 엉뚱한 데서 온도가 뚝 떨어진다
- **연애**: 다가가는 대신 상대를 통째로 외우며 먼발치에서 마음만 깊어진다 / 상대도 표현이 적으면 혼자 식었다 짐작하고 먼저 조용히 물러선다
- **사회**: 회의에서 걸리는 게 있어도 분위기 가라앉힐까 봐 끝까지 삼킨다 / 의미가 고이지 않은 일엔 손이 안 가고 결이 닿아야 깊이 움직인다

### 물INFJ
- **핵심기질**: 지나간 대화 한 토막을 며칠씩 되감으며 숨은 뜻을 캐요 / 눈앞 사건보다 그 사람이 왜 그랬는지를 먼저 더듬어요
- **강점**: 말로 괜찮다 해도 안 괜찮은 걸 알아채고 먼저 챙겨요 / 분위기가 가라앉은 자리에서 무엇이 어긋났는지 금세 감 잡아요
- **약점**: 해석을 멈추는 스위치가 없어 최악의 결말을 골라 믿어버려요 / 혼자 상상을 키우다 일어나지도 않은 일에 미리 지쳐버려요
- **연애**: 확신이 설 때까지 티 안 내고 상대를 한참 지켜만 봐요 / 상대 기분 따라 내 결을 맞춰 흐르며 빈틈을 메워줘요
- **사회**: 무리 한가운데보다 한 발 빠진 자리에서 더 편해요 / 낯선 모임에선 먼저 분위기에 스며들어 조용히 섞여요

### 물ENFP
- **핵심기질**: 사고의 출발점이 늘 내가 아니라 상대 쪽으로 먼저 기운다 / 관심이 한곳에 고이지 못하고 낮은 데마다 번져 흩어진다
- **강점**: 막혀 굳은 자리에 스며들어 물꼬를 터 다시 흐르게 한다 / 사람마다 다른 결을 바닥 읽듯 감지해 거기 맞춰 흐른다
- **약점**: 싫은 걸 삼키다 한 번에 둑이 터진다 / 벌여만 놓고 고이기 전에 다른 데로 샌다
- **연애**: 좋아하면 상대의 일상 구석까지 조용히 스며들어 적신다 / 상대 기분에 따라 내 온도까지 같이 오르내려 출렁인다
- **사회**: 끼리끼리 갈린 무리 사이를 오가며 끊긴 물길을 잇는다 / 새 판이 트이는 자리로 가장 먼저 흘러들어 자리잡는다

### 물ENFJ
- **핵심기질**: 물밑은 늘 분주한데 수면은 평온하게 다려 두는 편이다 / 남이 뭘 느끼는지부터 감지하고 자기 판단은 뒤로 미룬다
- **강점**: 위축된 사람과 들뜬 사람에게 말의 온도를 다르게 맞춘다 / 끊긴 말을 다시 띄워 조용한 사람도 한 번은 입을 떼게 한다
- **약점**: 남 기분은 즉시 읽으면서 자기 힘든 건 끝내 말 못 한다 / 거절이 안 나와 다 떠안고는 집에 와 혼자 후회한다
- **연애**: 상대 답이 짧아지면 무슨 일 있냐고 먼저 살핀다 / 뭐 먹고 싶냐 되물어 주는 사람한테만 마음이 풀린다
- **사회**: 회의 끝나고 표정 안 좋은 동료에게 따로 메시지를 보낸다 / 다들 고민을 털어놓아 남의 감정까지 떠안고 퇴근한다

### 물ISTP
- **핵심기질**: 겉은 잠잠해도 머릿속에선 끊임없이 원리를 따지고 있다 / 결론을 서두르지 않고 정보가 충분히 가라앉을 때까지 판단을 미룬다
- **강점**: 다들 당황하는 순간에 혼자 온도가 내려가 침착하게 손을 쓴다 / 말로 배우기보다 직접 만지고 뜯어보며 구조를 몸으로 파악한다
- **약점**: 머릿속 결론을 설명 않고 넘어가, 속을 모르겠다는 말을 듣는다 / 불편해도 내색을 안 해서, 참다가 혼자 손해 보는 쪽으로 흐른다
- **연애**: 좋아해도 거리부터 두고, 시간을 들여 아주 천천히 스며든다 / 사랑한다는 말보다 조용히 챙기는 행동으로 마음을 대신한다
- **사회**: 무리에 섞여도 한발 물러나 분위기를 관찰하는 자리에 선다 / 넓고 얕은 친분은 사양하고, 소수와 깊게 고이는 관계만 둔다

### 물ISTJ
- **핵심기질**: 판단을 서두르지 않고, 머릿속이 다시 맑아질 때까지 기다린다. / 단계를 건너뛰지 못하고, 차례차례 짚어야 생각이 정리된다.
- **강점**: 남들이 지친 일도 느리게, 그러나 멈추지 않고 끝을 본다. / 주위가 다급해져도 같이 휩쓸리지 않고 차분함을 지킨다.
- **약점**: 정해진 방식이 갑자기 바뀌면 쉽게 받아들이지 못하고 굳는다. / 서운함을 말로 꺼내지 못하고 속에 담아둔 채 오래 묵힌다.
- **연애**: 다정한 표현은 서툴러도, 챙기고 지키는 일에는 빈틈이 없다. / 마음을 단숨에 열지 않고, 시간을 들여 천천히 곁을 좁힌다.
- **사회**: 두루 친하기보다 믿을 수 있는 몇 사람과 깊게 사귄다. / 무리의 약속이나 순서가 흐트러지면 영 마음이 편치 않다.

### 물ESTP
- **핵심기질**: 계획을 세우기보다 상황의 흐름을 읽고 거기에 몸을 맡기는 편이에요 / 다들 허둥댈 때 오히려 머릿속이 차분하게 가라앉아 한 수가 보여요
- **강점**: 막힌 판에서 부수지 않고 가장 덜 막힌 길로 슬쩍 비껴 풀어내요 / 자리에 깔린 미묘한 긴장을 남보다 먼저 읽고 소리 없이 가라앉혀요
- **약점**: 변화 없이 멈춰 고이는 일이면 흥미가 슬그머니 다른 데로 새요 / 어디든 잘 맞춰주다 정작 내 입장이 어디 있는지 흐릿해져요
- **연애**: 좋아하는 마음을 말로 길게 풀기보다 그 자리 행동으로 먼저 적셔요 / 관계가 잔잔해지면 흐름이 멎은 듯 답답해져 식었다 착각해요
- **사회**: 어느 무리에 섞여도 튀지 않고 그 안에 스며 자리를 잡아요 / 누구한테나 편하게 대해 사람들이 어렵지 않게 다가오는 쪽이에요

### 물ESTJ
- **핵심기질**: 겉으론 칼같이 정해놓고 결정한 뒤가 더 길게 남아요 / 일을 덩어리로 안 보고 1번부터 순서로 머릿속에 깔아둬요
- **강점**: 엉킨 일도 여러 갈래를 한 줄기로 모아 흐르게 만들어요 / 막혀 고여 있던 일도 빠져나갈 길을 찾아 끝내 매듭지어요
- **약점**: 기준 안 지키는 사람은 말없이 다음부터 일을 안 줘요 / 쉬는 걸 일정에 못 넣어 빈 주말이면 청소라도 시작해요
- **연애**: 좋아하면 말보다 챙김으로 먼저 표가 나는 편이에요 / 다투면 위로보다 해결책부터 들이밀어 서운하게 해요
- **사회**: 다들 미루던 결론을 그럼 이걸로 가요로 끊어줘요 / 빈자리·정산·마감이 어느새 다 당신 몫이 돼 있어요

### 물ISFP
- **핵심기질**: 겉은 잔잔해도 속으로는 끝없이 가라앉아 생각을 곱씹는다 / 느낀 것을 말로 꺼내기 전에 안에서 한참 머금고 가라앉힌다
- **강점**: 남이 못 보고 지나친 미세한 결까지 알아채는 감각이 예민하다 / 어떤 분위기에 놓여도 거스르지 않고 자연스레 녹아든다
- **약점**: 싫은 내색을 안으로 삭이다 어느 순간 한꺼번에 무너진다 / 정해진 틀과 마감에 묶이면 기운이 눈에 띄게 시들어버린다
- **연애**: 좋아하는 마음을 직접 말하기보다 조용한 행동으로 적셔 보인다 / 한번 마음이 깊어지면 그 사람에게로만 잔잔히 고여든다
- **사회**: 나서지 않고 가장자리에 머물지만 자리에는 늘 있어준다 / 큰 자리의 소란보다 끝나고 남은 조용한 시간에 충전된다

### 물ISFJ
- **핵심기질**: 조용히 상대 기분부터 살피고 자기 판단은 늘 뒤로 미룬다 / 겉은 잔잔해도 속으로는 상황을 계속 곱씹어 정리한다
- **강점**: 사람들의 작은 변화를 빨리 알아채 먼저 보살핀다 / 한번 맡은 일은 티 안 나게 끝까지 책임지고 마무리한다
- **약점**: 밀려드는 부탁을 막지 못해 다 받다가 끝내 넘쳐버린다 / 서운함을 그때 말 못 하고 속에 고여 탁해지게 둔다
- **연애**: 표현보다 챙기는 행동으로 마음을 조용히 보여준다 / 한번 정 들면 깊고 오래 천천히 마음에 스며든다
- **사회**: 나서지 않고 뒤에서 무리를 받쳐주는 자리에 선다 / 티 안 나게 빠진 일을 메우며 분위기를 지킨다

### 물ESFP
- **핵심기질**: 옳고 그름을 따지기 전에 지금 누가 제일 흔들리나부터 보인다 / 머리로 손익을 재기 전에 좋다 싫다가 몸으로 먼저 온다
