- **아 그렇네: 8** — 01, 02, 03, 04, 05, 07, 08, 09

근거:
- **06 불ENTJ** — 제목 "회의실 공기가 제 쪽으로 기울어요", 마무리 "당신의 진짜 힘은 끌고 가는 게 아니라, 같이 가고 싶게 만드는 데서 나와요". 영웅서사·코칭조로 흘러 "내 얘기"보다 "멋진 사람 묘사"로 읽힘.
- **10 흙INFJ** — 제목 "흙으로 빚은 우물, INFJ"가 오행 이미지를 시적으로 박음(브리프 "있어보이는 표현" 경계). 본문은 아그렇네 수준이나 첫인상이 미화.

## 5. 파일럿 발견 사항 (풀 빌드 반영 후보)

1. **게이트 사각 — 구조 미검증**: 08 쇠ENFP 2차는 제목 줄이 통째로 빠진 채 도입부터 시작했는데도 elem/quote만 보는 게이트는 PASS. → 풀 빌드 게이트에 **[제목 1줄 존재 + 5섹션 구획]** 구조 체크 추가 필요.
2. **재생성 불안정 — 과교정 thrash**: 07 나무INTP 2차에서 에이전트가 자기검열로 무너짐(깨진 제목 "Editor pull-up...", 영어 혼입 "I need to stop and correct course", 다중 false start). 최종 클린본만 추출해 저장. → 재생성 프롬프트가 과교정 유발. failReason에 "스크래치/자기수정 출력 금지, 최종본만" 명시 + **출력 정제 단계** 파이프라인화 필요.
3. **융합라인이 elem 초과의 단일 병목**: 특히 wood/metal에서 lex 충돌어가 일상어와 겹침(`자라(다)`·`끊(다)`·`날`). → 융합라인 토큰 예산을 명시적 1개로 더 조이거나, lex를 형태소 경계로 정밀화(예 `자라`→`자라나`만, `끊어`/`끊는`만).
4. **메타 머리말 누출**: 04·08 1차에서 "~텍스트입니다" 류 머리말 출력 → 저장 전 첫 제목 이전 줄 제거를 자동화.
5. **곧은따옴표 정규화 효과**: 출력형식에 ASCII `"` 강제 → 전 슬롯 quotes 11~18로 quote 게이트는 0건 실패. 인용 부족은 병목이 아님(현 병목은 100% elem).

## 6. Go / No-Go 권고

**조건부 GO.** 1차 80% · 재생성 1회로 100% 도달 · ESCALATE 0 → 코어 통과율은 풀 빌드 진행 기준 충족.

선결 조건(풀 빌드 착수 전):
- (a) 게이트에 **구조 체크**(제목+5섹션) 추가 — §5-1
- (b) **출력 정제 단계**(머리말/스크래치 제거) 파이프라인화 — §5-2, §5-4
- (c) 재생성 프롬프트에 과교정 억제 문구 + lex 충돌어 정밀화 — §5-2, §5-3
- (d) 단일 저지 → 풀 빌드에선 다수 저지/디덥 연동으로 미화 드리프트(06·10 류) 차단 검토
